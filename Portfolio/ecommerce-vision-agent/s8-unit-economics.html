S8 Milestone

商业化模型与单位经济账 (Unit Economics)

从边际成本极度坍缩中捕获商业价值：B2B SaaS 95% 毛利是如何算出来的？

ToB 的核心永远是“算账” (ROI)。客户不会因为“AI很酷”而买单，他们只为“降本增效”买单。同样，一款 AI SaaS 产品的健康度，取决于其底层的 单位经济模型 (Unit Economics, UE) 是否能在刨除 GPU 算力成本后，依然保持极高的毛利率。本章节将剥丝抽茧地核算平台每处理一个 SKU 的真实账单。

01 单位经济模型对决：传统人工 vs AI 自动化管线

我们以生成 1 个服饰类 SKU（包含抠图、换场景、打光、合规审查与文字排版）为基准单位，进行成本拆解对照：

成本项拆解 (Cost Breakdown) 传统外包/人工成本 本 AI 自动化管线成本
执行耗时 (Turnaround Time) 约 3 - 5 天 约 15 秒
1. 图像剥离 (SAM抠图) ¥ 5.00 (精修美工) ¥ 0.01 (SAM API 摊销)
2. 场景与光影生成 ¥ 20.00 (实景影棚+摄影师) ¥ 0.12 (ComfyUI / SDXL 算力调用)
3. 动态文字排版 ¥ 5.00 (视觉设计/排版) ¥ 0.005 (SVG 渲染引擎)
4. 合规与违禁词审查 ¥ 5.00 (运营/法务人工核对) ¥ 0.01 (Agent.Critic / VLM 视觉大模型)
单 SKU 综合边际成本 ¥ 35.00 / SKU ¥ 0.145 / SKU

商业结论： AI 管线将边际成本降低了惊人的 99.5%。这种量级的成本坍缩，赋予了我们在商业定价上极大的降维打击空间。

02 商业变现设计 (Monetization & SaaS Margin)

有了极低的边际成本，我们在商业化定价（Pricing Strategy）上绝不售卖“API 算力”，而是直接售卖“业务交付结果 (Business Outcome)”。

SaaS 订阅与用量定价双轨制 (Hybrid Pricing)

采用“基础平台年费 + SKU 生成阶梯扣费”模式：

  • 客户侧定价： 每成功导出一套多平台 SKU 营销图，收费 ¥ 3.00（仅为传统成本 35元的不足十分之一，客户极度乐意接受）。
  • SaaS 毛利率 (Gross Margin)： (¥ 3.00 - ¥ 0.145) / ¥ 3.00 = 95.1%。
  • 这使得产品同时具备了传统 SaaS 的极高毛利特性，以及按需计费（PLG）的规模化扩张能力。

定价哲学：为什么坚决【按成品计费】而不是【按算力/GPU计费】？

不同的管线（复杂的外景重绘 vs 简单的室内打光）耗费的 GPU 时长确实天差地别，但作为商业中台，我们在前端面对客户时，必须坚决执行“按交付成品计费”，将底层的算力波动黑盒化。

  • 迎合客户的“心理账户”：电商总监的预算表里只有“单个 SKU 拍摄成本 100 元”，他们无法理解且极度厌恶“GPU Token、排队耗时”这类不可控的黑盒计费。按成品算，能极大地降低 B 端销售的摩擦力。
  • 赚取“确定性风险溢价”：如果我们按算力卖，我们就沦为了阿里云的“二道贩子”，利润极薄。正是因为我们（SaaS方）替客户承担了“AI 抽卡失败、Agent 重试”的算力沉没成本，我们才能把成本 0.15 元的图卖到 3.00 元，赚取高达 90%+ 的风险溢价。
  • 倒逼产研团队死磕“一次通过率”：如果按算力收费，用户生成的废片越多，平台反而越赚钱，这会导致产研失去优化模型的动力。只有按成品收费，公司为了保住利润，才会死磕 PRD 中提到的“前置质检”与“合规拦截”，逼迫技术团队把“人工接管率”压到 5% 以下。

03 高级 PM 视角的隐形成本陷阱 (Hidden Agent Loops)

如果一份 UE 报告只算到上面那一步，那只能算刚及格。对于拥有“状态机”和“自循环重试 (Self-correction Loop)” 的 Agentic 系统来说，必须将 废片重试与人工接管成本 算入其中。

必须考虑 Agent 的循环成本乘数 在 S5 PRD 的状态机中，如果 Critic Agent 发现合规问题（如 UI 死区碰撞），会触发最高 3 次的自动重新生成。这意味着一个“难啃”的 SKU，可能会消耗 3 倍的算力成本（¥ 0.145 × 3 = ¥ 0.435）。即便如此，¥ 3.00 的售价依然能够覆盖这种最劣情况 (Worst-case scenario)，保持近 85% 的毛利。
人工接管率 (Takeover) 即利润吞噬者 S6 设定的 5% 失败红线，其背后是极其残酷的经济账：一旦机器生成失败，任务转入人工工作台兜底，这 5% 的 SKU 成本就会立刻反弹回 ¥ 35.00 甚至更高。这也是为什么整个产品线不卷“生图画质”，而是死磕“一致性与确定性管线”的底层商业逻辑。
