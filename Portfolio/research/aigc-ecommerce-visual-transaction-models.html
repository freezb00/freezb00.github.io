AIGC 电商视觉交易模型、计费体系与履约结算边界深度调研

核心 Thesis

AIGC 电商视觉的商业交易本质，是将高风险、高沉没的「传统实体资产商业摄影 CapEx」解构并重包装为「极高毛利、按计算步数转嫁方差风险的虚拟代币/API 弹性 OpEx」；厂商通过在法律与协议中牢牢掌握裁判权切块，实现了 90%+ 的算力转售毛利与 15%-25% 的代币到期沉淀利润。

生成式 AI 具有确定性的底层硬件算力成本（GPU 秒数与显存占用），但出片效果却具备显著的统计学不确定性（行业平均抽卡废片率高达 30%-40%）；同时电商转化存在严重的端到端归因断裂，导致纯结果导向的商业模型（Outcome-based，如按增量 GMV 抽成）无法确立无争议的清算基准。由此，全行业最终收敛于「底费 + 虚拟代币 (Credits)」与「API 阶梯按量」的稳态度量衡体系。服务商的核心护城河不仅在于工程化压降 GPU 推理成本，更在于通过产品工作流把真实成本仅 0.5-1.5 分钱的单图推理以数十倍加价售出，同时在服务协议中彻底免除一切商业转化、假图违规与主观美学纠纷责任。

1. 核心结论（5 条）

结论 1：四大主流交易模型的结构特征与适用边界

  • 1. 混合代币制 SaaS 订阅（「底费 + 虚拟代币 Credits」——主流 C 端与中小 B 端模式）：用户按月/年支付基础会员费（298 - 2,998 元/年），获赠一定额度点数（1,000 - 15,000 点），超出部分加购点数包。核心商业秘密在于代币到期清零沉淀（Breakage）：由于电商上新具有强烈的淡旺季周期，未消耗点数平均沉淀率达到 15% - 25%，直接免除算力履约成本转化为纯利润。
  • 2. 纯 API 阶梯按量计费（开发者、代运营机构与电商 ISV 模式）：无强制前置底费，按 HTTP 接口成功次数计费（Photoroom $0.02/张，Claid $59/千点）。用量越大单价越低（百万次以上下探至 0.05 - 0.10 元/张），采用预充值资金池或月结账单。
  • 3. 企业定制化私有方案与合规保险交易（头部品牌与跨境大卖家模式）：单合同 10 万 - 100 万元以上，包含私有模型部署、风格定制、专属并发池以及商业版权侵权代偿兜底（IP Indemnification）。将不可控算力购买转变为可对抗法务诉讼的合规保险购买（Adobe Firefly 模式）。
  • 4. 代运营效果分润与佣金抽成（非标准服务商模式）：收取低底费并绑定店铺增量 GMV 1%-3% 抽成。但由于归因争议过大，90% 以上合作最终依然退回传统的「按款打包」或「按图结算」。

结论 3：履约承诺账与裁判权切块（谁握判定合格的笔）

  • 裁判权切块原则：厂商通过用户服务协议（ToS）将裁判权完全切给机器执行事件本身——「只要生图接口返回了图片文件，履约即视为成功」。至于服装是否有色差（ΔE > 2.0）、模特手指是否扭曲、买家是否退货，厂商在法律上明确免责。
  • 废片补偿机制：主流 SaaS 均设计「有限补偿」：用户在 24 小时内对畸形图片点击申诉，系统审核后退回消耗的 1 点代币。该机制将赔偿边界严格锁定在虚拟代币内，严禁任何法币现金退款，彻底杜绝现金流回撤风险。
  • 平台违规责任转嫁：针对亚马逊 AI 披露与主图实拍红线，厂商均在免责条款中声明由用户自行承担平台合规责任，因违规使用 AI 图片导致店铺降权扣分，平台概不赔偿。

来源依据：[1][4][5][7]

  1. 多变量混杂导致增量因果推断失效：电商下单是商品定价、品牌力、大促折扣、运费险与好评率的综合结果，永远无法剥离证明销售是由图片带来还是由降价带来。商家在盈利时归因于运营能力，在亏损时归因于图片失真退货。
  2. 两端激励错配与道德风险：若按点击率（CTR）付费，AI 工具将有强烈动机生成夸张、过度美化的「照骗」以骗取点击，导致退货率暴增，由商家承担损失。
  3. 数据主权与审计壁垒：商家绝不可能向第三方生图工具开放核心店铺财务后台，无法建立可信的对账底账。

最终推论：任何强行尝试 Outcome-based 的视觉工具，最终都会在经历频繁的对账仲裁与恶意白嫖后，重新倒退回「按生图动作消耗点数」的前置确定性结算。

3. 局限与失败模式（交易模型设计的三大暗礁）

  • 失败模式 1：盲目照搬传统 SaaS 纯「无限量席位订阅」导致算力亏损
    早期部分厂商为获客推出「99 元/月无限量出图」，被代运营或爬虫脚本 24 小时并发调用，单月烧穿数千元 GPU 成本，直接打穿现金流，迫使厂商紧急下线改回点数制。
  • 失败模式 2：代币到期规则过于苛刻导致用户流失
    月末强制完全清零未用点数引发淡季商家极大被剥夺感，次月商家全员逃逸至支持结转或纯 API 的竞品，导致客户留存率（NRR）跌破 60%。
  • 失败模式 3：忽视大客户法务合规需求，沦为小微低价内卷
    产品仅提供匿名充值与普通模型生图，缺乏版权侵权代偿兜底协议，无法进入年预算百万级的 500 强采购链，陷入小微低毛利泥潭。

魔鬼代言人反向审视与隐含假设挑战

反向挑战 1：如果大模型厂商（如 OpenAI、Google）直接将多模态生图 API 降价到 0.001 美元/次，第三方商拍 SaaS 的 50-100 倍加价空间是否会瞬间归零？
回应：基础模型价格战确实会压低纯 API 批发价，但商拍 SaaS 售卖的不是裸模型 API，而是「服装人台姿态锁定、面料几何防畸变微调 LoRA、多图层 PSD 导出与批量上新模板」这一整套垂直工程管线。商家付费购买的是「降低废片率与可商用性」，只要垂直工作流能帮商家节省美工挑选时间，40-80 倍的工作流封装溢价依然稳固。

反向挑战 2：代币到期沉淀（15%-25%）是不是不可持续的「割韭菜」套路？
回应：代币到期清零确实存在负面用户体验摩擦，但它本质上是厂商为了对抗「高昂备用算力集群的固定折旧支出」。如果允许永久无限期结转，厂商就必须常年为历史售出的海量未消耗代币维持巨额的待命 GPU 集群，从而承受极高的闲置破产风险。因此，成熟厂商会演变为「点数按季度有限顺延」，在平滑用户被剥夺感与保护自身现金流之间取得平衡。

Bear 悲观情景 (15%)

开源 ComfyUI 端侧化普及，商家自建边际成本归零，交易退回纯算力批发价（<0.01元/张）。

Base 基准情景 (70%)

「底费 + 消耗点数 + API 阶梯包」维持绝对主流。20% 代币沉淀与垂直微调锁定腰部商家，高端卖合规保险。

Bull 乐观情景 (15%)

广告投放闭环打通，确权无争议的增量因果归因跑通，正式落地 Outcome-based 效果分成交易。
