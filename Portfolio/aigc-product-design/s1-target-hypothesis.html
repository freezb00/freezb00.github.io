目标用户画像 · 商业插画师与工作流断点

目标角色：自由商业插画师 / 独立创作者 · 产品形态：宿主插件 + 交付监视总线

核心结论：目标用户首选自由商业插画师（触达性最高、痛感最直接）。形态上确立关键反常识：绝不做脱离现有工作流的独立 Web 画布，插画师生存在 Photoshop / Illustrator / Procreate 中，产品必须以「宿主插件（PS/AI UXP Panel）+ 交付监视总线」的形式寄生在既有工具链中。

01目标画像与决策理由

维度画像详情
目标角色自由商业插画师、独立视觉设计师、接单画手（全职接单或副业高频接单）。
主要承接品类品牌商业插画、包装外观配图、图书/杂志绘本、电商大促 KV、素材库（站酷海洛）供稿。
客群选择逻辑可触达性极高：小红书、米画师、站酷、涂鸦王国、插画接单微信群均有密集体量；且没有 B 端采购审批漫长周期，单人即可完成安装与付费决策。
核心使用工具链Photoshop (主力) + Illustrator (矢量/印刷) + Procreate (手绘草稿) + Midjourney/SD/Flux (垫图或局部灵感辅助)。

02调研：画师现有的四套“土办法”与惨烈代价

在没有交付层工具前，画师在定稿后被甲方挑刺时，不得不使用以下四套笨拙土办法：

① 文字硬改：PS 套索 + 仿制图章 + 涂抹补底
甲方要改标语或修正错字。因 AI 生成的是扁平图，画师先套索抠出原字，用仿制图章/内容识别或外挂 Inpainting 把被遮挡的底纹涂抹补平，再打上新字。
代价：底纹经常出现色块断层、模糊边缘，修补 1 处文字耗时 30~60 分钟；多次修改后画面整体质感崩溃。
② 绝望重抽：重新跑 Prompt + 蒙版拼贴
改动较大时，只能回生图软件换词重抽。受限于 C2（身份不持久）与 C4（多样性互斥），新图的五官、色调、光影全变了。
代价：不得不把新图和旧图拖进 PS 做局部蒙版拼合，反复修接缝色差，一个微调单子耗费半天，还被甲方质疑“怎么前后画风变了”。
③ 暴力色彩转换：PS 菜单直切 CMYK
印厂要求交 CMYK，画师在 PS 中直接点击「图像 → 模式 → CMYK」，然后保存为未转曲的 PSD。
代价：RGB 高饱和亮色（荧光绿、明黄、宝石蓝）发生灾难性色彩坍缩变灰；且字体未转曲、未内嵌，印厂打开缺少字体文件报错，打样被退回。
④ 人工打包与截图自证
手动在本地建 4 个文件夹（预览/全清PNG/CMYK印刷/源文件），按规范逐一另存；被质疑版权时，将草图图层、生成日志截图拼成长图自证。
代价：打包与重命名耗费 1~2 小时；版权证明毫无司法规范效力，依然被强势甲方找借口扣款。

03靶心卡五栏（核心定义）

靶心维度定义与推导S3 访谈检验问题
① 结算场景与时刻 交付日前 24–48 小时：甲方终审提出文字/排版调整，或印厂工程人员发来预检失败告警。 “你上一次在定稿交付后被客户要求改文案或被印厂退单是什么时候？当时距离截止时间还有多久？”
② 失败代价量化 无偿返工 4–8 小时；因打样报废赔偿 200–1000 元；尾款拖欠 2 周至 2 个月（涉及合同总额 30%–50%，即 1500–8000 元）。 “最近半年有没有因为格式、色差或版权争议被扣尾款或反复返工的经历？损失了多少工时或真金白银？”
③ 替代方案花费 买 Photoshop/Creative Cloud 年费、购买第三方修图脚本、付费请助理兼职切图打包（每次 50–100 元）。 “为了应付最后的交付格式与色偏，你目前买了什么插件或工具？有付钱找人帮忙修图过吗？”
④ 付费转移逻辑 按交付项目计费（19–39 元/单次交付包）或季度专业订阅（59–99 元/月）。预算从“被扣的尾款风险”与“外包修图工时”中平移。 “如果有个工具能在 PS 里一键搞定改字补底、合规转曲 CMYK 和交付打包，帮你稳稳拿到尾款，你愿意每单付多少钱？”
⑤ 关键反常识 Thesis 工作流寄生原则：绝不逼画师去独立 Web 端。工具必须是 Photoshop/Illustrator 宿主插件，在设计师已有画布内一键解决。离开 PS 的独立交付工具必死。 “如果必须把图上传到一个新网页去处理，和在 PS 右侧边栏直接点一个按钮，两者的体验差异对你有多关键？”

04产品形态裁决：原生插件 vs 独立 SaaS

架构形态：PS/AI 原生 UXP 扩展面板 + 本地轻量处理引擎

为什么不能是独立 Web 工具：
插画师绝不会把一个 500MB 的多图层 PSD 导出成 PNG，传到网页端做处理，再下载回本地。这增加了 3 次格式转换和中断。
正确形态：在 Photoshop 扩展面板中常驻。当画师导入 AI 底图或绘制完草图后：
1. 文字安全层剥离：点击一键分离文本安全区，底层由本地轻量 Inpainting 自动补齐无缝纹理；
2. 合规预检仪表盘：在画板侧边实时显示 RGB→CMYK 色域溢出告警、出血辅助线检测；
3. 一键 Handoff 导出：后台调用转曲与 ICC 映射算法，自动在项目文件夹生成规范的交付物料包与版权时间戳记录。
