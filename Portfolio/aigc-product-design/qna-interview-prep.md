# Handoff · AI生图分层与商用交稿插件 —— 面试/立项评审高频 Q&A 题库

本文档梳理了在展示该项目时，技术高管或业务负责人可能会提出的“地狱级”拷问，以及对应的降维打击式回答策略。

## 一、 产品战略与生态位 (Product Strategy)

### Q1：为什么选择做 Photoshop 插件，而不是自己做一个类似 Canva 或 Web 端的独立工作台？
**💡 回答策略：打出“工作流寄生”与“用户心智”的底牌。**
* **参考话术：** “专业画师在交付前的最后一步，100% 必须使用数位板进行人工降级精修（修补 AI 画错的手指、精细调色）。如果做独立的 Web 画布，是在逼迫用户改变现有习惯，且无法提供媲美 PS 的专业绘画体验。我们选择开发 PS UXP 插件，实行的是**‘工作流寄生’策略**。我们不去卷前端的生图工具，而是直接卡在他们最痛苦的‘交付最后一公里’，做现有工作流的增强补丁，这样获客阻力最小，且粘性最高。”

### Q2：底层大模型（如 Midjourney、Flux）进化极快，如果未来它们原生完美支持了分层和 CMYK 导出，你的产品是不是就被颠覆了？
**💡 回答策略：将产品定性为“履约节点”而非“算力套壳”。**
* **参考话术：** “大模型解决的是‘概率生成’问题，而商业交付要的是‘绝对确定性’，你不能指望底层大模型替你盖章签合同。我们的核心护城河并不在‘生图’，而在于后端的**印前体检标准（Pre-flight）与版权存证链（Blockchain 确权）**。当行业内 30% 的画师都习惯用我们的规范标准打包交付时，我们就成了行业的基础设施（Infrastructure）。不管底层是 OpenAI 还是 Midjourney，只要它们还在输出视觉元素，就需要经过我们的管线进行合规化封包。我们是裁判，不是运动员。”

## 二、 技术可行性与工程架构 (Tech & Architecture)

### Q3：为什么解耦文字非要用 SAM 2 + 本地 Inpainting，直接用文生图重画透明背景不行吗？
**💡 回答策略：强调商业单对“像素级锁定”的刚需。**
* **参考话术：** “商业单修改有一个致命前提：**牵一发不可动全身**。如果用文生图或图生图重跑透明图层，哪怕固定了随机种子（Seed），画面边缘细节依然会发生不可控的偏移，这是扩散模型的物理特性决定的。我们采用 SAM 2 提供亚像素级的精准 Mask，再配合极低重绘幅度的 Inpainting，能确保画面中‘不需要修改的地方’实现 100% 像素级锁定。这是商业画师敢把工程文件发给客户的技术底线。”

### Q4：既然要用 SAM 2，为什么还要搞“端云协同”，全放云端或者全放本地不行吗？
**💡 回答策略：秀出你对算力成本控制（FinOps）和用户体验的极致权衡。**
* **参考话术：** “全放云端会带来灾难性的 GPU 算力成本（尤其是极度耗费算力的 Inpainting），导致我们的毛利被吞噬；全放本地则会导致包体过大、初始化极慢。所以我们采用了**非对称算力架构**：将 SAM 2 轻量级的特征提取（编码）放在云端，实现毫秒级交互响应；而将吃显存、耗算力的 Inpainting 补底推给画师本地的电脑（画师通常标配 4090 等高阶显卡）。这种‘吃大户’的策略，既保证了极速体验，又将最昂贵的算力成本转嫁给了边缘端。”

## 三、 商业化验证与 UE 模型 (Commercialization)

### Q5：你们定价 19 元/单，但你核算的单次云端算力成本只有 0.14 元，这种“暴利”定价能跑得通吗？画师不会觉得太贵吗？
**💡 回答策略：运用 B2B 锚定定价法，从“算力计费”升维到“价值计费”。**
* **参考话术：** “对于生产力工具，绝不能按算力成本来定价。在这个场景下，画师花 19 块钱买的不是 API Token，而是**‘节省了 2 小时的手工重绘时间’**以及**‘能顺利拿到 5000 块尾款的安全感’**。我们将定价锚点定在画师的时薪（200元/小时）和外包单价（几千元）上，19 元（一杯咖啡的钱）在这个业务杠杆里显得极其便宜。这正是 B2B 工具能实现高溢价的秘密。”

### Q6：在 GTM 灰度测试中，如果发现即使产品很好用，画师也不愿意花 19 元，你的战略熔断机制是什么？
**💡 回答策略：展示敏捷的 Pivot（业务转向）能力和深刻的用户洞察。**
* **参考话术：** “如果在灰度邀请测试中，我们发现激活率很高，但付费转化率持续为 0，这说明画师群体过于价格敏感，‘花钱买时间’的逻辑在 C 端走不通。此时我们会立即触发战略熔断，转向 **B 端游戏工作室/广告公司（企业老板买单）**。打法会变为：将插件对接包的画师免费开放，但向发包方（老板）收取‘企业级验收规范审查费’。因为对老板而言，拿到标准化、无版权风险的源文件，是绝对的刚需。”
