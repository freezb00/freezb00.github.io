出版级 AI 绘画工作台 · 交互原型功能与模块规格说明书 (Prototype Specification)

版本：v1.0
定位：面向出版级工业化 AIGC 生产线的端到端交互沙盘原型设计规范 (Interactive Sandbox Prototype Spec)
对标业务：教材教辅、儿童绘本（40页长篇叙事）全业务链路工业化闭环
配套文档：PRD 01（全局架构与商业化）、PRD 02（工作流与画布）、PRD 03（LoRA资产化）、PRD 04（质检与合规）

一、 原型定位与设计目标

1.1 核心命题与演示目的

传统 AIGC 绘画工具多停留在“单张独立生图、碰运气抽卡、扁平位图无法修改、缺乏物理印刷标准”的玩票阶段。本交互原型旨在构建一个高保真、可沉浸式操作的工业级 SaaS 生产中台沙盒，直观展现如何将 AIGC 的概率性输出重构为高度确定性、合规闭环的现代出版流水线。

1.2 演示实战载体案例

原型以实战项目 《森林里的小兔子》第 3 册（40 页幼教连续绘本） 的端到端生产作为全景体验载体，完整跑通从文字大纲录入到最终印厂交付的全部核心动作。

三、 画布系统：双层视口架构规格 (Dual-Viewport Canvas)

原型彻底抛弃“无物理约束的纯涂鸦无限画布”，采用针对出版场景的**“定开本受控画板 ＋ 外围无限分镜看板”双层视口架构**：

3.1 视口 A：全书分镜故事板无限画布 (Infinite Storyboard Canvas)

  • 视口特性：
    • 支持无极缩放（Zoom 10% ~ 400%）与平滑漫游（按住空格键/鼠标右键自由拖拽平移 Pan）。
    • 具备网格点阵底纹背景与物理坐标系统。
  • 分镜画板矩阵 (Multi-Artboard Grid)：
    • 横向/网格平铺展示整本绘本的 40 个分镜开本画板 (Page 01 ~ Page 40)。
    • 允许主编和插画师统揽全书连贯视觉流：包括色彩冷暖节奏演进、翻页动线以及角色面部与服饰的跨页一致性。
  • 外围自由草稿与垫图区 (Scratchpad / Moodboard Area)：
    • 画板四周的无限空间可摆放“角色三视图基准卡”、“Pantone 专属色盘”、“分镜灵感草图”。
    • 跨画板拖拽：支持将外围资产卡中的主角头像直接拖放注入某个画板，该画板即刻继承该角色的提示词和一致性编码。

3.2 视口 B：定开本受控印刷画板 (Focused Print Artboard)

  • 触发机制：在无限画布中双击任意单页分镜（如双击 Page 03），视口以平滑摄像机动画聚焦放大进入定开本精修模式。
  • 物理尺规与印刷合规准线 (Print Rule Overlays)：
    • 物理毫米标尺 (mm Ruler)：边缘显示真实大度 16 开（210 × 285 mm）物理尺度。
    • 3mm 出血切线 (Bleed Box)：外围标红 3mm 裁切警戒线，防止切边露白。
    • 装订中缝安全区 (Gutter Safe Margin)：左侧或右侧显示 10~15mm 胶装阴影区，预警人物主体与文字严禁贴近装订线。
    • 版心文字安全区 (Text Safe-Zone)：显示顶部 30% 留白框，确保排版字行不遮挡插画主体。
  • 图层管理与局部重绘：在此视口下呼出非破坏性图层树，支持针对单一图层执行交互式笔刷修复。
  • 退出机制：点击“返回全书总览”或缩小视角，平滑退回无限故事板。

四、 核心业务流水线：5 大阶段功能模块详细规格

阶段 01：文稿智能解构室 (Script Parsing & Safe Text Area)

  • 所属角色：文字编辑 / 策划主编
  • 输入内容：原稿故事文本（提供内置样本文稿《小兔子拔萝卜》一键载入按钮）。
  • 核心交互与功能：
    1. LLM 语义拆解：点击“结构化解析”，模拟打字机动画提取分镜场景 Prompt、光影基调、学科事实要素。
    2. 敏感词与事实初检：自动扫描文本是否含有意识形态风险或少儿违禁词汇。
    3. 分镜卡片流：将长篇文本拆解生成 4 组带有编号的标准分镜镜头需求卡。
    4. 文字安全区留白计算：根据文稿字数自动计算该页顶部所需的留白面积比例（如 25%~35%）。
  • 产出交付物：结构化分镜脚本元数据、文字安全排版约束。

阶段 02：画风 LoRA 与角色资产锁定 (Consistency & Style Lock)

  • 所属角色：美术监修 / 算法工程师
  • 核心交互与功能：
    1. 角色选择与特征激活：在主角“圆耳朵小白兔欢欢”和配角“红松鼠皮皮”之间切换，激活绑定的 IP-Adapter 特征。
    2. 专属画风 LoRA 调用：选择《出版社专属水彩水粉风 v2.1》，支持滑动调节 LoRA 权重系数（0.6 ~ 1.0）。
    3. 一致性实时测算面板：展示当前算法管线预估的“面部一致性置信度 (95.8%)”和“色彩漂移率 (4.2%)”，直观印证 PRD 02 核心指标。
  • 产出交付物：角色基准特征包、画风权重配置包。

阶段 03：分层画布编辑器与交互式局部重绘 (Layer Canvas & Inpaint) —— 【核心高光】

  • 所属角色：插画美编 / 视觉设计师
  • 核心交互与功能：
    1. LayerDiffusion 原生图层解耦管理：
      • 图层 1：排版文字与安全区标记层（Eye 开关 / Lock 锁定）
      • 图层 2：前景角色层（小兔子与萝卜主体，支持透明通道单独提取）
      • 图层 3：中景道具与篱笆层
      • 图层 4：背景草地与远山天际层
    2. 刻意预设瑕疵诊断：画面初始状态下，小兔子手部存在“手指粘连/多余肢体”这一典型的 AI 生图瑕疵。
    3. 交互式 Mask 涂抹笔刷 (Inpainting Brush)：
      • 用户点击左侧“选区笔刷”工具，在兔子手部瑕疵区域进行涂抹，出现半透明红色蒙版选区。
      • 支持调节笔刷半径（Brush Size）。
    4. 局部提示词定向重绘：
      • 提示词框输入：“修复为标准少儿卡通四指爪子，自然握持胡萝卜叶”。
      • 点击“执行局部重绘”，模拟 2 秒异步任务调度，手部瞬间修复，背景和衣服 100% 保持完全不变。
    5. Before / After 动态比对滑块：用户可左右拖拽分割线，对比修复前后的像素级细节。
  • 产出交付物：高保真分层修图工程稿件。

阶段 04：VLM 多模态初筛与三审三校在线批注 (Quality Gate & Review Loop) —— 【核心闭环】

  • 所属角色：责任编辑 / 终审专家
  • 核心交互与功能：
    1. VLM 四级质检漏斗仪表盘：
      • 政治与意识形态安全：100% PASS（绿色）
      • 学科事实与常识准确度：98% PASS（绿色）
      • 少儿形体与审美达标度：初始预警为 82% WARN（检测出手部畸变）
      • 印刷物理工程指标：待印前校验
    2. 责编在线圈点批注工具：
      • 责编可在画面任意坐标框选打标，添加便签批注（如：“Page 03 兔子领口纽扣颜色应为黄色，当前为白色，不符合设定”）。
    3. 【核心闭环】逆向驳回返修回路 (Review Reject Loop)：
      • 点击“❌ 质检驳回并派发工单”按钮，系统触发返修动画，工单直接回流至 Stage 03 分层画布，并自动定位到错误图层和批注区域，模拟 15 分钟内快速返修闭环。
    4. 终审合格签发：
      • 点击“✅ 三审三校合规通过”，画面中央印上鲜艳的红色“出版审校合格电子签章”，解锁 Stage 05。
  • 产出交付物：三审三校签署工单、质量审查溯源记录。

阶段 05：印前工业超分与 CMYK 分色出片 (Pre-Press & CMYK Purifier)

  • 所属角色：印制排版组 / 印刷厂对接人
  • 核心交互与功能：
    1. 300 DPI 出版级超分对比：
      • 提供 72 DPI (屏幕预览) 与 300 DPI (出版超分) 切换，放大查看细微毛发与纸张纤维质感。
    2. CMYK 印刷胶印色域模拟滤镜：
      • 切换 RGB 屏幕色 vs CMYK 印刷打样色，模拟真实油墨吸收造成的轻微饱和度变化，防止印后色差废版。
    3. K100 纯单色黑文字提纯开关：
      • 开启/关闭单色黑对比：直观演示“四色黑 (CMYK) 套印重影模糊”与“K100 纯单黑刀刻般锐利”的工艺差异。
    4. 3mm 出血裁切自检：
      • 自动校验四周出血位内是否有关键图文被误裁。
    5. 工业交付物导出：
      • 点击“导出工业印刷包”，下载包含分层 PSD、印刷高清 PDF 以及 C2PA 版权哈希存证文件的打包清单。
  • 产出交付物：印刷分层 PSD 母版、300 DPI CMYK 印刷高精 PDF。

五、 全要素资产中台模块规格 (Asset Hub Specification)

在原型主界面可通过快捷入口打开 企业级资产抽屉 (Asset Center Drawer)，包含四大子模块：

5.1 角色全要素资产卡 (Character Model Cards)

  • 展示内容：
    • 角色三视图（正面、侧面、45度仰角透视基准图）。
    • 冻结特征标识：FaceID: #4096-VEC、IP-Adapter Weight: 0.85。
    • Pantone 标准色盘锁定（如身体毛色：Pantone 11-0601 TPG、衣服色：Pantone 17-1563 TPG）。
    • 常见情绪表情矩阵（开心、惊讶、疑惑、难过）。

5.2 出版社专属画风 LoRA 库 (Style LoRA Hub & Studio)

  • 展示内容：
    • 当前出版社已训练好的私有画风资产列表（如《阳光绘本风 v2.1》、《国风线描水墨风 v1.2》）。
    • 轻量训练向导模拟 (No-Code LoRA Studio)：
      • 15~50 张正交样本清洗标准规范卡。
      • WD14 结构化自动打标预览（正向特征词提取、背景干扰词剔除）。
      • 过拟合拦截雷达图 (Overfitting Benchmark)：展示风格泛化度、角色依从度、色彩漂移度雷达打分。

5.3 开本版式与留白模板库 (Layout & Safe-Zone Library)

  • 展示内容：
    • 大度 16 开（210 × 285 mm）绘本模板。
    • 正度 16 开（185 × 260 mm）教材模板。
    • 自动带入 3mm 出血位与 12mm 中缝装订装订线。

5.4 资产反哺增值闭环 (Asset Mining & Feedback)

  • 核心交互：
    • 终审项目完成时，支持点击“一键入库反哺”，系统自动将该书的高评分插画切片脱敏归档入社内模型库，使专属画风越用越聪明。

六、 RBAC 权限协同与多租户隔离规格 (RBAC & Multi-Tenant Engine)

6.1 顶栏 4 角色切换器联动机制

原型顶栏常驻角色切换胶囊组件 [文字编辑 | 美术监修 | 责任编辑 | 印制工程师]，点击切换后，整套工作台的按钮可用性、编辑权限与侧边栏进行动态限制：

协同角色 允许操作的核心模块 被限制/禁用的越权操作
文字编辑 文稿录入、LLM 分镜拆解、排版留白调整 禁改插画底层算法与 LoRA 参数；禁签发终审合格
美术监修 资产库调用、LoRA 权重调节、分层画布操作、笔刷局部重绘、提交审校工单 禁擅自审批通过三审三校；禁改动印前分色物理曲线
责任编辑 VLM 质检看板查看、在线画圈批注、派发驳回返修工单、电子签章终审放行 禁直接篡改美术图层（权责分离，仅能圈选提返修）
印制工程师 300 DPI 超分控制、CMYK 色彩滤镜校准、单色黑分离、出血位检验、导出印刷包 在三审未通过前本模块全局锁定；禁止改动故事文稿

  • 物理隔离提示：社内专属 LoRA 库标注 [私有沙箱隔离中 · 禁止跨社泄漏]。

七、 界面布局与组件设计规范 (UI/UX Specification)

  • 设计语言：沉浸式暗色/深灰专业生产力工具风格（类似 Figma / Linear / Adobe UXP / VS Code）。
  • 主界面划分：
    1. Top Bar (高 56px)：项目信息、租户徽标、角色切换器、全书任务进度、算力 Token 监控。
    2. Left Flow Nav (宽 68px/220px)：5 大阶段步骤切换（带当前节点完成度徽标）。
    3. Center Main Canvas (自适应弹性视口)：
      • 无限分镜画布模式（多画板平铺 + 缩放拖拽）
      • 定开本受控精修模式（物理标尺 + 出血线 + 局部 Inpainting 笔刷）
    4. Right Inspector & Agent Copilot Panel (宽 320px · 双模态)：
      • ⚙️ 属性面板模式：根据当前选中的步骤，动态切换“分镜属性”、“图层树”、“LoRA控制”、“质检雷达”、“印前参数”等。
      • 🤖 协同 Agent 对话模式：常驻出版协同智能体（策划/美术/审校/印前 Sub-Agent），支持 @画板P03 实体感知、思维链 (CoT) 展开、可执行提案卡片（一键应用至画布）与自然语言人机协同。
    5. Bottom Status Bar (高 32px)：显示 ComfyUI 集群状态、GPU 延迟（45ms）、当前画布坐标与物理缩放比。
  • 技术规范：
    • 单文件极速加载：采用纯原生 HTML5 + CSS3 + 纯原生 ES6 JavaScript，零外部编译依赖，双击在任意浏览器即可满血运行。
    • 矢量保真：界面内所有画板、标尺、切线、三视图及示意图均采用 SVG 动态矢量与 Canvas 绘制，极致清晰。

八、 验收与交互验证路径 (Walkthrough Demo Path)

原型交付后，可通过以下标准动线进行 5 分钟完整演示：

  1. [文字编辑] 载入文稿 ➔ 点击 LLM 拆解 ➔ 查看 4 组分镜与顶部文字安全区。
  2. [美术监修] 打开资产抽屉 ➔ 检查小白兔 FaceID 资产卡 ➔ 开启专属画风 LoRA。
  3. [无限画布] 缩放平移浏览整本 40 页分镜全景 ➔ 双击 Page 03 进入定开本印刷画板。
  4. [Agent 对话协同] 切换至 🤖 协同 Agent 对话 ➔ 识别责任编辑工单 #042 ➔ 点击“自动规划 P03 手部重绘” ➔ 展开思维链 CoT ➔ 点击卡片“一键执行并应用到画布” ➔ 自动触发 SAM 2 笔刷局部重绘并实时修复手部。
  5. [责任编辑] 切换责编视角 ➔ 审校合规 Agent 自动跟进 ➔ 查看质检雷达 ➔ 画圈批注 ➔ 模拟驳回工单 ➔ 再次提交后点击“三审合格签发”（盖红色公章）。
  6. [印制工程师] 切换印制视角 ➔ 印前 Agent 联动 ➔ 开启 300 DPI 超分与 CMYK 胶印模拟 ➔ 检验 3mm 出血位 ➔ 导出分层 PSD/PDF 工业物料包。
  7. [资产反哺] 终审通过后，点击将成稿一键反哺沉淀至社内专属 LoRA 库。
