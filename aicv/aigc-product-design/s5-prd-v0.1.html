S5 PRD v0.1 · AI生图分层与商用交稿插件系统控制

2026-09-17 · 载体：Photoshop UXP 原生扩展面板 · 附加维度：控制力与经济学

MVP 三步流敲定降级路由 Fallback 覆盖毛利模型测算完成

工业级生成式系统的核心壁垒，在于构建一张能够在恶劣非确定性环境中存活的异常降级网（Fallback Routing）。
本篇 PRD 不设想理想化的“一键全自动”，而是定义了严格的系统状态机、熔断边界与人工接管触发器。将高并发识别交由云端大模型处理，将最终的编辑确定性平滑交还至设计师的手工图层。

00业务系统全景 (Business Panorama)

在进入具体功能交互前，需明确本产品（Handoff 管线）在整个插画商业化生命周期中的生态位与上下游边界：

01核心交互链路：Handoff 三步流

画师在 Photoshop 中完成 AI 草图导入或手绘绘制后，打开右侧 Handoff 面板：

Step 1：一键图文解耦（Text & Object Decoupling）
└─ 框选含文字/主体的区域 → 点击【智能解耦】
└─ 结果：原图层被静默分为 [独立文字层 (可双击编辑)] + [主体层] + [底纹修补层]。

Step 2：印前工业体检（Pre-flight Check）
└─ 点击【体检】 → 视口叠加红色热力图，暴露出血位缺失、RGB 荧光色在 CMYK 域内的死区。
└─ 点击【智能修复】 → 一键延伸 3mm 边缘出血，高饱和色做基于人眼感知的 ICC 色域映射压缩。

Step 3：一键闭环打包（Delivery Packaging）
└─ 勾选目标（印厂 PDF / 站酷 EPS / 网页 PNG），点击【导出并存证】。
└─ 结果：桌面生成规范 ZIP，内含格式完全对标工业要求的文件，外加 PDF 版本《原创履约存证链》。

02非确定性控制：状态机与 Fallback 降级路由（🔥 核心亮点）

生成式 AI（如 Inpainting 补底）天生具有不确定性。我们不强求算法 100% 完美，而是用工程手段兜底。以下是 图文解耦管线 的严密状态转移控制：

系统状态 / 输入特征置信度探测路由动作 (Happy Path)Fallback 降级与兜底

复杂边缘场景
文字压在半透明烟雾、发丝或极复杂纹理之上		 Confidence 60%–85% 分离文字成功，但 Inpainting 预测接缝可能存在瑕疵。 半自动挂起：生成「修复图层蒙版」，但不在画布直接合并；高亮面板红点，提示画师检查并用 PS 画笔手动修缮边缘。

03单位经济学模型 (Unit Economics)

定价模式：次卡结算

画师的痛点是“交稿拿尾款”，因此收费模式应锚定“单次成功交付”，而非宽泛的月租包。定价策略：19 元 / 单次交付项目包（打包 10 个以内文件+ 1 份版权存证）。

算力与存储成本项 (COGS)单次项目消耗预估成本费用测算
1. 图层分割模型 (SAM 2 / BiRefNet) 调用云端 GPU 推理，平均 3 次抠图解耦 ~¥ 0.04 (基于 T4 GPU 租赁均价)
2. Inpainting 智能补底模型 调用云端生图修复 API，平均 2~3 处补底 ~¥ 0.08 (按 Token / 调用次数估算)
3. 色域映射与印前转换算子 纯本地 C++ 算子 (利用 PS SDK) + WASM ¥ 0.00 (无云端成本)
4. 哈希上链与存证存储 存储时间戳哈希值，轻量上链 ~¥ 0.02
总可变边际成本 (单次项目) 包含所有 API 与存证消耗 总计约 ¥ 0.14

毛利护城河验证： 单次定价 19 元，单次边际成本 0.14 元，毛利率高达 99.2%。这意味着该产品在单位经济学上极度健康，核心成本是早期研发固定投入（PS UXP 开发与 C++ 算子封装），而非生成式大模型那种每调一次都在流血亏本的结构。

04概率式验收门槛 (MVQ - Minimum Viable Quality)

不要设定 100% 完美的玄学指标，设立研发在测试环境可以打靶计数的硬规约：

  1. 解耦补底不闪退率（可用性）：大文件 (2GB+ / 300图层) 下解耦执行崩溃率需低于 0.5%，一旦 OOM 必须 3 秒内进入纯本地 Fallback。
  2. 人工介入容忍度（拦截率）：对 50 张标准商业用图测试，要求 Confidence < 60% 触发人工接管的比例控制在 15% 以内（允许 15% 的极端长尾图交给画师自己搞，不追求完美算法）。
  3. 交付合规率（准确性）：用 100 张导出好的 CMYK PDF 丢入 Adobe Acrobat 工业预检脚本跑查，色标错误、出血缺失与未转曲的拦截报错率必须为 0%。
