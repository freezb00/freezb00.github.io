约束驱动功能推导 · 约束的余数

方法论：功能不是凭空想出来的，是物理与工作流约束反向挤压出的唯一解

本项目的产品推导公式：
功能集合 = (物理硬约束 + 工业规范 + 工作流习惯) 排除不可能方案后的确定余数。
本方案的 7 项核心功能，每一项都能严格溯源到一条特定的不可违抗约束，没有一处是拍脑袋的“创意”。

01约束映射与功能推导总表

约束来源与代号约束内核推导出的确定功能坚决枪毙的功能
物理约束 C1
潜空间无图层		 扩散模型输出的是单张烘焙位图，内部不存在对象与矢量路径。 F1 · 智能解耦与图层容器化
在 PS 内通过轻量分割算子将位图智能分流为主体层、背景层，生成规范命名的 PSD 图层结构。		 宣传“AI 原生生成多图层 PSD”
物理约束 C3 + C4
下采样吞噬汉字 + 随机种子不可复现		 模型内部无法准确渲染中文汉字；重新生图必然导致全图光影与画风崩塌。 F2 · 文字安全区保护与无损改字引擎
生图时剥离文字引导留白；在宿主内将文本作为独立 TrueType/OpenType 矢量文本层渲染；改字时利用局部 Inpainting 无损补平背景，底图 100% 像素不动。		 改文案时重新调用生图模型全图重抽
工作流约束
公理四：寄生原则		 商业画师生存在 PS/AI 内，绝不接受把 500MB+ PSD 上传到 Web 页面处理再下载。 F3 · Photoshop / Illustrator 原生 UXP 面板
作为宿主软件侧边栏插件常驻，直接读写当前 Active Document，零格式转换中断。		 独立 Web SaaS 在线画布
色彩物理约束
RGB 屏幕 vs CMYK 印刷		 屏幕高饱和荧光色在 CMYK 四色油墨色域外，简单转换必然造成灾难性发灰发脏。 F4 · 实时 CMYK 溢出热力图与软打样
在 PS 视口中实时用色块标出溢出区域，提供一键保感知对比度的智能色域映射压缩算法。		 无色彩管理的单纯“另存为 CMYK”
印刷工业约束
3mm 出血与刀模规范		 印刷厂裁切机械误差必须有 3mm 画面延伸，扁平生图直接裁切会导致边缘露白。 F5 · 智能 3mm 边缘延伸出血算法
基于边缘纹理智能向外扩展 3mm 出血位，自动标出裁切线与安全线。		 让画师手动在画布外圈用画笔生硬涂抹
平台分发约束
站酷海洛 / 印厂 / Web 差异		 各渠道对转曲、单画板、DPI、文件体积有一票否决的死规定。 F6 · 一键多场景 Handoff 打包器
勾选用途（印刷、Web、素材库），后台全自动生成转曲 EPS、PDF/X-4、超分 Retina PNG，打包为规范 ZIP。		 通用的“导出高清大图”按钮
信任与法务约束
C6 误杀 + 司法判例 + 尾款		 甲方以版权不清拒付尾款；司法判例要求必须自证创作链路与个性化介入过程。 F7 · 原创商用权属存证黑匣子
记录 Prompt 演进、草图时间戳、手工图层修饰历史与差分比对，一键生成带防伪哈希的《版权履约存证证书》。		 抹去所有生成记录的黑盒导出

02单项推导剖析：F2（无损改字引擎）的推导链条

01 痛点证据
甲方定稿后要改标语，画师花 2 小时套索抠字 + 仿制图章，结果底纹质感严重破坏。
02 模型硬约束
C3（VAE 下采样）决定了模型画不出合格汉字；C4（不可复现）决定了重跑整图画风必变。
03 架构推论
汉字绝对不能在生图模型内部渲染，文字必须是宿主软件内拥有字形渲染引擎的独立文字对象。
04 工程兜底设计
文字下方必须有完整的底纹。当文字移动或换词时，被遮挡区域必须瞬间由轻量 Inpainting 补齐；且模型对“预留安全区”的遵循是软约束，系统必须有硬算法检测文字区域底色纯净度。
05 落地功能形态
F2 无损改字引擎：在 PS 画板中双击文字直接编辑，底层纹理自动动态补齐，全图其余区域像素 100% 冻结不变。

03功能优先级划分（MVP 裁剪刀）

发布周期包含功能验收门槛
P0（MVP 核心） F2 无损改字 + F3 PS 原生 UXP 面板 + F4 CMYK 色差预检 + F6 一键 Handoff 打包 画师能在 15 分钟内完成以往耗时 2 小时的改字与打包，印厂直出合格率 100%。
P1（体验增强） F1 智能解耦分层 + F5 智能 3mm 边缘延伸出血 对复杂主体与背景的分离准确率达到 85% 以上，减少手动抠图工时。
P2（商业闭环） F7 原创商用权属存证黑匣子 + 站酷海洛供稿格式一键合规 存证报告通过品牌法务审核，尾款拖欠周期缩短 70%。
