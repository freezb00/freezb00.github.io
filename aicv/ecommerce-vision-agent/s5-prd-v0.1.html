S5 Milestone

AI 出图自动化平台 核心 PRD (v0.1 草案)

一份高级 PM 的 PRD 不仅仅写“正常流程怎么走”，更要写“系统崩了怎么办”。

本 PRD 定义了 AI 出图自动化平台 (电商视觉 AIGC 交付引擎) 的 全量核心功能模块。
作为一个企业级 B2B SaaS，我们的产品不是一个单一的“聊天框”，而是一个由 四大业务模块 组成的流水线：数据资产接入 ➔ 企划编排 ➔ 无头渲染 ➔ 质检与人工兜底。

01 产品全局功能架构 (Feature Matrix)

整个系统面向电商视觉主管与美工，提供以下全链路功能：

模块一：数字资产库与数据摄入 (Asset & Data Layer)

  • SKU 原片管理池：支持从本地拖拽或绑定云盘，批量导入白底图/实拍原图，自动提取 SKU 唯一标识。
  • 内置轻量级数据引擎 (Data Table)：摒弃沉重的 ERP 直连，提供类似 Airtable 的内置数据面板。运营人员直接上传 Excel/CSV 快照，在系统内部维护“促销价、满减规则”，极速开展批处理。
  • 断开外部强依赖：规避漫长的 IT 接口对接，业务人员对自己上传的活动数据拥有 完整管理权，随时修改，即刻重绘。
  • 品牌矢量资产库：支持企业上传具有独家版权的 `.otf / .ttf` 字体包及矢量 Logo，确保最终图文排版的品牌一致性。

模块二：多模态企划引擎 (Planner Agent)

  • 大促策略画布：运营通过简单的文本描述（如：“双11秋季上新，主打法式清冷感，小红书 3:4 比例”），Planner Agent 自动将意图转化为结构化的渲染参数。
  • 竞品舆情爬取与卖点生成：输入竞品链接，Agent 自动抓取差评与痛点，反向生成当前 SKU 的文案 Hook（如：“别买起球的毛衣，看这件纯羊毛”）。

模块三：Agentic 核心自动化流水线 (Execution Pipeline)

流水线完全基于实际调试跑通的工作流（ComfyUI + 多智能体协同）构建，不含任何不可落地的黑盒：

  • 1. 前置质检 (Agent.QC)：使用轻量级视觉 Agent 自动拦截画质过低、角度奇葩的商品原图，阻止脏数据进入下游。
  • 2. 精确抠图 (SAM 3)：纯后台静默运行，对商品主体进行 100% 像素级物理边缘剥离，拒绝模型幻觉和特征变形。
  • 3. 场景生成 (ComfyUI)：基于企划意图，动态调用 ComfyUI 工作流底座，生成符合商品几何透视的真实电商场景。
  • 4. 阴影重建 (NormalMap)：通过法线贴图与深度信息，重构商品与背景的接触阴影 (Contact Shadow) 和环境光反射，消除“抠图悬空感”。
  • 5. 动态排版 (SVG DOM)：放弃 AI 画字，调用底层无头浏览器，将 ERP 传来的实时价格标签以矢量形式绝对精准地叠加在画面安全区。
  • 6. 合规风控 (Agent.Critic)：多模态审查 Agent 在出图前进行最后一道体检，拦截形变、六根手指、违禁词与 UI 碰撞。

模块四：人工兜底工作台 (Human-in-the-loop Dashboard)

  • 跨平台 UI 死区碰撞检测：内置抖音/淘宝/小红书的前端 UI 蒙版参数。一旦生成的文字落入“购物车”或“评论区”按键范围，引发碰撞，系统即刻打回。
  • 广告法 OCR 违禁词扫描：在出图前进行最后一次字符扫描，包含“全网第一”、“最强”等极限词自动阻断。
  • 人工兜底工作台 (Dashboard)：将上述环节中重试失败的任务（约占 1%）挂起，在 UI 侧显示醒目的红点。美工在此工作台中，可直接拖动错位的文字层或替换价格，保存后即算完结。
  • 资产一键分发与打包：审核完毕的任务，支持导出为 合并 JPG 用于直接上架，同时导出 保留文本图层的 PSD，有效保留设计师的后续修改权。

03 核心调度状态机 (Core State Machine)

对于模块三与模块四之间的批处理流转，我们定义了极其严苛的异常处理状态机，确保无人值守时的稳定性：

状态 (Status) 触发条件与系统行为 下一步流向
Queued (排队中) 接收到 ERP 价格数据和商品主图，等待 GPU 算力池空闲。 ➔ Generating (算力就绪)
Generating (生成中) 调用后端无头管线生成背景、阴影，排版引擎合成文字。 ➔ Auditing (等待质检)
Auditing (质检中) 触发 Critic Agent（广告法扫描 + UI蒙版碰撞检测）。 ➔ Success (通过)
➔ Critic_Failed (不通过)
Critic_Failed (打回重试) 被 Critic 拦截。系统会自动携带修改参数（如缩小字号 10% 或下移 50px）触发自动重排，重试上限 3 次。 ➔ Generating (重试 < 3次)
➔ Human_Review (重试超限)
Human_Review (人工兜底) 机器三次重试失败（如文字极长无法避让），任务挂起，进入人工干预工作台。 ➔ Success (美工手动拖拽完成)
Success (可导出) 合规且通过质检。生成打包好的分层 PSD，归档。 ➔ Archived (归档)
