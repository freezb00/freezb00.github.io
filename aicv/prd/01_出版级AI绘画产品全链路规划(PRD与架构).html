📌 方案推演闭环 · 初始角色资产的三大真实来源（严禁盲目假定凭空生成）
在实际出版业务中，角色资产绝非凭空产生，也不是靠无休止地盲盒抽卡，而是通过以下 3 条工程路径在 1~2 天内完成定型入库：
  • 路径 A · 存量系列 IP 资产化（成本为 0）：针对已出版的历史童书、经典教辅续作，直接导入往期 5~15 张高清原图，半天内提取 IP-Adapter / FaceID 拓扑向量与 LoRA 权重，即刻完成全书资产绑定。
  • 路径 B · 原创重磅新书 —— 美编/画师仅出 1 张核心母版（降本核心）：画师从“画整本 32 页重复苦力”转为“美术指导”；仅需绘制 1~2 张主角正面 Anchor 基准概念图（耗时 1~2 天），系统自动提取潜空间特征并投射至全书 30+ 页面，后续全由系统继承。
  • 路径 C · 低客单价教辅 —— 多维属性受控打样（拒绝纯抽卡）：编辑通过年龄、发型、服饰与画风属性选择器，结合标准站姿 ControlNet 预处理器，并发生成 4~8 组标准三视图候选卡；编辑仅需 1 次决策勾选“设为全书主角”，后续分镜全部强约束复用。
🛡️ 工业化核心机制 · 为什么每个流程都必须设立「人工校验门禁 (Stage-Gate)」？
严肃出版的工业化流水线绝非“无人驾驶黑盒”，而是标准的 Human-in-the-loop（人机协同门禁制）：
  • 法律与终身责权不可委托：出版实行“三审三校”与责编终身责任制，AI 无法律主体资格；政治红线、常识勘误必须由人类编辑签字签章背书。
  • 阻断错误级联扩散 (Error Cascade)：前序环节（如分镜或角色设色）若偏差 5%，后续 32 页将全线报废；工段门禁确保“未经人类验收，下游流水线决不启动”。
  • 人类角色质变（从画画苦力 ➔ 决策机长）：AI 承担 85% 繁琐耗时的生成与图层运算（体力劳动），人类专家仅在每个 Gate 节点花费 5~15 分钟进行“圈选、微调、签字放行”，实现真正的低摩擦交付。

2. 核心业务矛盾深度剖析

  1. “泛娱乐生图”与“出版严肃性”的矛盾：C 端产品（如 Midjourney、原生 WebUI）追求单张图片的“惊艳感”与发散性，依赖抽卡；而出版业要求“高度确定性”（角色跨页同一性、生物与科学知识准确性、色彩空间 CMYK、3mm 出血位及 4mm 跨页中缝接版规范）。
  2. “非专业编辑”与“底层复杂参数”的矛盾：图书文字编辑不懂复杂的 Prompt、采样步数、CFG、Denoise 与 ControlNet 预处理器；系统必须将技术复杂性沉淀在底层工作流，前台提供结构化的文稿解析与“所见即所得”的画板交互。
  3. “图文割裂”与“版面排版协同”的矛盾：传统 AI 生图往往“把画面画得太满”，导致文字对话框与课文正文无处安放；出版级产品必须在文稿解析阶段即锁定版面意图（Layout Intent）与文字安全区（Text Safe Area）。

三、 出版级数据实体模型 (Data Entity Schema)

为支撑“整本图书”维度的资产继承、画风锁死与版本管理，系统抽象出严格级联的 四层出版级数据实体模型：

Level 1 · 工程级 📚
Project
整本图书顶层工程实体
  • Book_Meta 书名、ISBN 书号、目标读者年龄段、责任编辑团队
  • Print_Spec 开本规格 (大度16开/32开)、成品尺寸、3mm 出血位标准
  • Global_Style_LoRA 全书默认画风 LoRA UID、全局触发词、调色曲线 LUT
  • Color_Profile 印刷色彩配置标准 (ISO Coated v2 / FOGRA39 CMYK)
↳ 级联包含：1 : N Spreads 印张
Level 2 · 印张级 📖
Spreads / Pages
跨页 / 单页印张实体
  • Page_Number 逻辑页码与物理页码 (P01~P32)、单双页偶奇属性
  • Gutter_Margin 跨页中缝装订避让区 (跨页预留 4~6mm 视觉防挤压安全线)
  • Bleed_Boundary 外扩 3mm 物理裁剪出血线 Mask 区域
  • Spread_Type 单页插画 / 左右跨页全景图 (Double Spread) / 图文环绕
↳ 级联包含：1 : N Shot 分镜单元
Level 3 · 分镜级 🎬
Shot / Frame
单幅分镜与画面构图单元
  • Camera_Framing 景别规格 (全景远景 / 叙事中景 / 特写表情 / 俯视仰角)
  • Bound_Characters 绑定出场角色资产 UID 列表 (主控 IP LoRA / 特征向量)
  • Text_Safe_Zone 排版留白遮罩 (30%~45% 文字占位区负向生成引导)
  • Prompt_Assembly 装配后正反向提示词、ControlNet 骨骼/线稿权重组合
↳ 级联包含：1 : 1 Canvas 会话
Level 4 · 资产渲染级 🎨
Canvas Session
分层画布渲染与出片会话
  • Base_Background 背景环境图层 (环境 Outpainting 完整全景图)
  • Foreground_Subjects 独立主体角色图层 (BiRefNet 抠图 RGBA 透明通道)
  • Inpaint_Version_Chain 历史重绘图层链 (局部涂抹修正、手部修复差异 Mask)
  • Export_Master_Bundle 工业导出包 (300 DPI 分层 PSD / CMYK 嵌入式 TIFF)
↳ 终审归档：进入印刷印制库

四、 产品整体架构设计 (AI 出版创作工作台)

系统采用高内聚、低耦合的 “三层驱动架构”，打通从前端业务交互、中台工作流调度到异构算力引擎的全链路支撑：

TIER 1 · 业务交互层 出版创作 Web 工作台集群 (Collaborative Web Studio)
面向文编、美编、责编与印务的 6 大协同作业功能室
01 文稿智能解析室 文字编辑
  • Word/TXT 一键导入与长文本智能分句
  • LLM 抽取环境/光影/角色要素并生成分镜脚本
  • 文字安全区与版面排版留白引导标记
02 全书出版级资产库 美术主管
  • 角色三视图、专属画风 LoRA 与调色 LUT 标准库
  • 场景空间 (环境/光影) 与核心道具/器物资产绑定
  • 版式网格模板 (出血位/文字安全区) 与印刷标准 ICC
03 导演级分镜概念台 文编 / 美编
  • 全书 32 页跨页缩略图全局网格看板
  • 单分镜 1:4 / 1:8 并发方案极速打样对比
  • 景别视角 (远/中/特写) 与镜头节奏动态编排
04 分层画布精修编辑器 美术编辑
  • 主体与背景智能自动抠图分离 (RGBA 透明图层)
  • 局部涂抹 Inpainting 手部修复与表情精修微调
  • 跨页中缝 4mm 避让线与 3mm 出血位辅助标尺
05 VLM 审校与知识质检台 责任编辑
  • 画面涉政/涉暴/少儿读物合规红线大模型筛查
  • 历史常识、自然科学事实多模态 RAG 交叉核验
  • 角色服饰特征跨章节漂移报警与返工工单系统
06 工业印刷预检与出片台 印务排版
  • RGB 转 FOGRA39 / JapanColor CMYK 软打样
  • 出版级 300 DPI 矢量无损超分上采样引擎
  • 文字单色黑 K100 提纯、总墨量限制与分层 PSD 导出

五、 核心业务模块与功能规划 (PRD 核心设计)

1. 文稿智能解析与分镜提取模块 (Text-to-Storyboard)

  • 用户输入：上传 Word/PDF 或纯文本（例：“小明背着蓝色的书包，走在洒满阳光的银杏树大道上，树旁有一只正在捉蝴蝶的橘猫”）。
  • LLM 抽取与结构化装配引擎：
    • 场景要素拆解：时间（晴天上午）、环境（银杏树道、金黄落叶）、主体（小明：男童/蓝书包）、辅体（橘猫/蝴蝶）。
    • 构图与视角建议：自动建议构图镜头（如：全景远景/侧面中景）。
    • 版面留白约束注入（Layout Constraint）：识别插画所在版面的正文排版区（如：上方留白 35% 用于排版文字），自动在 ControlNet / 生成指令中注入构图限制，防止主体穿透文字区。
    • 结构化参数输出：转化为与后台图像模型直接绑定的结构化 Prompt、Negative Prompt 与姿态骨骼线。

2. 出版级全要素资产中心与产品化 (Multi-Dimensional Asset Hub)

严肃出版物并非孤立生成单图，而是依赖严谨的“全要素资产继承网络”。系统将零散的生成参数沉淀为五大类出版专属资产，支持全局跨章节引用与强一致性继承：

  • 角色资产（Character Asset）：
    • 多视角基准图与特征锚定：建立主角正/侧/背三视图与面部特征向量（Face Embedding / IP-Adapter），保证全书面容完全一致。
    • 差分状态集：配置喜怒哀乐表情库、特定年龄阶段、四季服饰预设与标准色标。
    • 唯一 UID 绑定：在分镜提示词中输入 @主角UID 即可自动装配特征向量与姿态骨骼约束。
  • 画风与笔触资产（Style Asset）：
    • 定制专属画风 LoRA：支持出版社/工作室上传 15~30 张版权插画自动微调，沉淀出版社私有画风模型。
    • 笔触与质感保持：水彩晕染度、国画白描线稿、油画肌理质感等关键参数严格锁死。
    • 全书调色曲线 (LUT)：统一整本书的色彩饱和度与明度区间，杜绝不同章节画风浓淡割裂。
  • 场景与空间资产（Scene / Environment Asset）：
    • 固定三维空间透视：对故事常驻环境（如“主角书房”、“森林木屋”、“学校教室”）建立固定地标与空间透视关系。
    • 光影天气模板：预设晴昼、黄昏金光、雨夜等标准环境光照与 Depth 深度控制模板。
    • 跨页全景延续：支持单环境在跨页（Double Spread）接缝处透视与比例无缝衔接。
  • 核心道具与器物资产（Prop / Object Asset）：
    • 关键叙事器物：固定传家宝佩剑、特定科学实验仪器、专属交通工具等形态，杜绝前后章节形制变形。
    • 历史文物与科学图解还原：结合 ControlNet 线稿对齐特定历史朝代文物形制或现代精密结构。
    • 手持交互标准化：预置角色持握道具的标准姿态骨骼与遮挡蒙版。
  • 版式模版与印前规格资产（Layout & Color Spec Asset）：
    • 开本与物理边距模板：大度16开/大度32开出血位（3mm）、跨页中缝（4~6mm）避让线、天头地脚安全区网格预设。
    • 图文排版留白遮罩库：针对左图右文、上图下文、跨页压图、环绕排版等不同版式，提供文字安全区负向注意遮罩。
    • 目标印刷色彩标准 (ICC Profile)：绑定 FOGRA39 / JapanColor 2001 色彩配置文件与油墨总量 (TAC < 300%) 极限参数。
  • 多层级资产权限与物理隔离：
    • 社级公共资产库 (Enterprise Library)：集团出版社经典 IP 角色与公版插画画风，跨编辑室共享。
    • 书目专属私有库 (Project Private Bucket)：单本图书立项专属的角色微调模型、场景与线稿，租户级加密隔离，结项后支持打包归档，确保版权绝对安全。

3. 多分镜画板与局部编辑交互 (Canvas Editor)

  • 分镜连环画板模式：一屏展示整本图书的 16/32 个页面分镜，保证整体视觉节奏统一。
  • 局部确定性编辑：
    • 选区重绘（Brush Inpainting）：画笔涂抹不满意区域（如手部、道具），结合局部提示词重新生成，保持其余背景 100% 像素不动。
    • 参考图替换（Reference Swap）：允许编辑上传特定道具照片（如特定型号显微镜、特定历史时期军装），通过局部 ControlNet 精确替换。
    • 分层输出（Layer Export）：前景人物、背景环境、文字图层分离输出，前景抽离后自动执行背景空洞填补，便于美编后期进入 InDesign/Photoshop 调整排版。

4. VLM 知识质检与三审三校在线协同 (Review & Inspection)

  • 多模态机审漏斗：VLM（多模态大模型）针对生成画面执行三重自动质检：
    • 意识形态与风控红线：政治地图完整性、民族服饰合规性、宗教禁忌与少儿安全审查。
    • 学科常识与科学事实：动植物生理结构（如昆虫足数、叶脉走势）、物理常识硬伤校验。
    • 文字遮挡告警：自动对比文稿文字安全区 Mask 与插画主体轮廓，发现重叠遮挡立即弹窗预警。
  • 在线审校流转与工单闭环：支持责编在画面上“划线批注”，系统自动将批注位置、修改意见绑定回对应画布工程，支持一键发起驳回返修工单。详细技术方案见 PRD 04。

5. 工业级印刷预检与色彩出片引擎 (Pre-Press & Color Engine)

  • 出版级超分辨率重建：针对 1024px 底稿，集成 Tile-ESRGAN / SUPIR 上采样算法，一键超分至 300 DPI 印刷级高精输出（单页物理像素达到 4000×5600 以上）。
  • 物理印刷标准合规套件：
    • CMYK 分色与软打样：挂载标准印刷 ICC 配置文件（如 Japan Color / ISOcoated），提供屏幕软打样偏色预警。
    • 正文字纯黑 K100 提纯：防止黑字被四色套印导致重影模糊，纯黑文字通道自动剥离提纯。
    • 出血位与裁切校正：自动校验四周 3mm 印刷出血位与 1.5mm 铣背裁切装订线，最终导出印刷级分层 PSD 与合规 TIFF。

七、 B 端商业化与数据指标闭环

1. 商业化模式（面向出版客户）

  • SaaS 席位费 + 算力包模式：
    • 基础席位包：按编辑账号收取年费（含基础模型调用与存储空间）。
    • 专属模型定制包：按套收取出版社专属画风/角色 LoRA 训练与微调服务费。
    • 算力资源阶梯包：按生成张数/高精度超分算力点数充值。
  • 商业 ROI 对比与可行性测算：
    • 传统外包：一套 30 页绘本外包美术成本 1.2~2.5 万元，周期 45 天；
    • 本方案推演测算：综合成本有望降至 1500~3000 元（含人工精修与算力成本），周期压缩至 3~5 天，测算降本 80%+ 综合制作成本。

2. 关键业务数据看板 (Data Metrics)

  • 效率与质量指标：
    • 首绘采纳率（First-Pass Acceptance Rate）：无需局部修改直接被编辑采纳的比例。
    • 平均返修轮次（Iteration Turns per Page）：单页达到出片标准所需的修改次数（目标 ≤ 2.5 次）。
  • 客户健康度指标：
    • DAU/MAU 活跃时长：编辑在画板上的平均停留时长与导出频次。
    • 老客续约率（Renewal Rate）与增购算力比例（Expansion MRR）。
