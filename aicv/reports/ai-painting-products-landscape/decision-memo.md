# 决策备忘录：AI 绘画赛道产品与商业化战略选择判断系统

## 1. 核心判断（Executive Thesis）

1. **“纯生图工具”作为独立 SaaS 的历史窗口期已正式终结**：
   随着开源 DiT 架构（如 FLUX.1）和前沿大模型原生多模态视觉生成能力的普及，基础生图能力已被快速降级为通用商品（Commodity）。缺乏特定工作流承载的独立工具，次月留存普遍低于 15%，无法抵御底层模型升级带来的降维打击。
2. **终局价值捕获被两极分化垄断**：
   - **极 A（协同操作系统极）**：以 Canva（收购 Leonardo）与 Adobe Firefly 为代表，通过将生成能力深度嵌入存量设计、排版与发布管线，彻底消除图元导出与外部修改断点，获得极高商业溢价；
   - **极 B（垂直生产力与资产网络极）**：以美图设计室（电商商拍高 ROI 替代）和 LiblibAI（双边开源创作者模型资产网络）为代表，通过解决商业交付中可量化的成本痛点或建立生态黏性立足。
3. **“算力变动成本”逼迫商业模式从伪无限走向严格计量**：
   硬件推理存在不可稀释的物理成本。未设配额与排队防线的“固定月费无限生图”必然陷入重度用户击穿毛利的恶性循环；必须采用“基础配额 + 潮汐降权排队 + 动态 Token 计量”的三级防爆仓架构。

## 3. 单位经济学与盈利红线（Unit Economics Guardrails）

在进行产品立项与商业化定价时，必须恪守以下四条核心财务红线：

1. **单图零售价与硬件成本的倍率缓冲**：
   - 商业 API / 用户点数扣减折算的单图收入，必须至少维持在底层推理硬件成本的 **3.5 ~ 4.0 倍** 以上，以吸收系统空载、网络传输、冷启动预热及 CDN 存储的隐性损耗。
2. **算力熔断与配额防线（Hard Cap & Throttling）**：
   - 任何订阅方案禁止开放无节制的并发 API 批量调用。一旦单用户当月生图量超过 500 张，必须自动降级至**低优先级共享队列（Relax Mode）**或触发点数充值。
3. **冷启动与显存利用率（Bin-Packing）阈值**：
   - 生产集群 GPU 整体利用率必须保持在 **65% ~ 80%** 的黄金区间。低于 60% 说明实例过度冗余造成闲置浪费；高于 85% 则会导致峰值排队时延飙升引发用户流失。
4. **ROI 导向的价值定价（Value-based Pricing）**：
   - 在 B 端电商或游戏设计场景中，切忌按“每张图几分钱”的算力成本思维向客户报价；必须锚定客户原有的替代成本（如实体摄影棚单次 3,000 元、修图外包单张 50 元），按节省成本的 10%~20% 制定订阅方案，赚取超额商业利润。

## 4. 二阶受益方与终局推演

- **真正的最大赢家：存量设计巨头与 Serverless GPU 算力中枢**：
  - **Canva 与 Adobe**：利用现有的 2.65 亿月活与企业级客户关系，在技术成熟期低成本集成生成能力，将 AI 转化为存量会员升档（Upsell）的最佳杠杆；
  - **云算力聚合平台（Fal.ai, Replicate, SaladCloud, Modal）**：无论上层具体哪款 AI 绘画产品胜出，只要推理请求量增加，算力聚合平台均能抽取稳定的基础设施过路费。
- **终局格局推演**：
  未来 3 年内，独立 AI 绘画网站将有 80% 以上退出市场或被传统设计/营销平台低价并购；剩下的 20% 将演化为**专业极客模型资产网络（如 Civitai/Liblib）**或**极端专业垂直工业软件插件（如影视游戏资产中台）**。

| 监测信号 | 触发阈值 | 潜在影响与修正策略 |
|---|---|---|
| **端侧算力突破** | 手机与 PC 芯片（如 Apple M系列 / 高通 / Intel）能在本地 1 秒内无损推理 10B+ 视觉大模型 | 云端租赁与点数计费模式面临冲击，软件必须转向纯客户端买断制或纯垂直资产包变现。 |

| **商业版权裁定转向** | 司法判例正式承认“通过复杂 Prompt 与交互调整的 AI 输出物拥有排他性独立版权” | 独立工具的版权合规门槛降低，企业客户采购阻力大幅消除，利好中小型专业生图平台。 |
