**功能差异点（PM 视角最重要的两条）**：
1. **图层拆分（layer decomposition）**：Seedream 5.0 pro/flash 支持「将单张图片拆分为 1 张底图和最多 16 个独立图层」，且图层拆分单价仅为同分辨率单图生成的 **50%**（0.15 vs 0.30）。这是目前国产图像 API 中少见直接输出**可编辑图层结构**的能力，直接指向「生成后可交付、可二次编辑」的设计工作流。
2. **交互编辑**：支持通过坐标、框选、箭头、涂鸦草图指定编辑区域，模型识别标记范围后回填内容。

分辨率：1K / 1.5K / 2K，输出 png/jpeg；5.0 flash 默认 2K，自定义尺寸 921,600 像素（1280×720）至约 462 万像素，宽高比 1:16~16:1（第三方站，[SINGLE_SOURCE]）。4K 输出需使用 Seedream 5.0 Lite / 4.5 / 4.0。

## 3. 可下注判断（每条挂引用）

### 判断 1｜模型调用价格已经收敛到 0.2 元/张这条线，计价差异转移到「分辨率 × 结构复杂度」而非「模型强弱」
阿里 wan2.6-t2i / wan2.6-image 中国区 **0.2 元/张** [S#12/S#13]；腾讯混元生图 3.0 后付费 **0.2 元/张**（= TokenHub 20,000 tokens/张 × 10 元/百万 tokens）[S#7]；字节 Seedream 4.0 **0.20 元/张** [S#3]，但 Seedream 5.0 pro 单图生成已抬到 **0.30 / 0.60 元/张**（按 261 万像素分档）[S#3]。
→ 三家在上一代主力模型上一致报 0.2 元/张，说明 0.2 是"基模商品化地板价"；下一代（5.0 pro / 2.7-image-pro）把价格锚点挪到了**分辨率与图层复杂度**。
→ **PM 行动**：做 ROI 模型时不要问"哪家模型便宜"，要问"我的场景需要 1.5K 还是 2K、需要扁平图还是可编辑图层"。Seedream 5.0 的图层拆分单价（0.15/0.30）比同分辨率单图（0.30/0.60）**便宜一半** [S#3]，这是字节在补贴"结构化输出"，值得作为工作流改造的切入点。
置信度：**high（A 级官方定价三源互证）**

### 判断 2｜应用层正在从"订阅"迁移到"订阅 + 算力点"，因为订阅给 ARPU 设了天花板
美图 CEO 原话：「訂閱檔位給消費金額設了一個天花板…… 2026 年上半年我們逐步在各產品中接入的 agent 能力，突破了這一限制」[S#16]；结果是 Q1/Q2 用户 AI 算力点消费环比各增超 46%、半年累计 +113% [S#16][S#15]，美图设计室已有**数千名用户年化消费达综合 ARPPU（≈¥200/年）的约 10 倍**，该群体自 2025-12 起增长约 6 倍 [S#16]。万兴表述同源：「商业模式正从传统订阅制向'订阅+Token 消费'双轮驱动拓展」[S#22]。
→ **PM 行动**：做 AI 绘画产品的商业化设计，至少要留一层"按消耗计价"的通道，且**用 Agent/复杂任务去触发消耗**（而不是用次数包），否则高价值用户会被价格档位锁死。
置信度：**high（A 级财报 + B 级媒体 + C 级工具站三方指向同一结论）**

### 判断 3｜"聚合 + 统一计量单位"是应用层对抗模型层的标准解法
稿定官网会员页直接列出自己接入的模型：Seedance 2.5、Seedance 2.0 Fast、万相 3.0、灵动图像 2.5、千问 Image 3.0 [S#8]；堆友集成 Flux.1 Kontext Pro、Nano Banana Pro 与自研 Qwen-mage [S#24]；万兴"双模驱动"自研天幕同时引入 Seedance 2.0、Vidu Q3、Kling 3.0 4K [S#22]；美图则明确用自研 + 第三方 API 编排 [S#16]。
→ 用户侧看到的是"豆/美豆/堆豆/灵感值"这个**统一换算单位**，模型只是被编排的资源。[S#8][S#18][S#24]
→ **PM 行动**：如果你做应用层，**"引进几个模型"不是壁垒，"用什么单位计价 + 怎样按任务路由模型"才是**。稿定的单位成本能做到 ¥0.18–0.63/张（本报告依据其官方豆价推算），而它自己不训底层模型。
置信度：**medium-high（两个 A 级官方页面 + 两个 C 级来源同构互证；但"应用层利润率"无公开数字）**

### 判断 4｜纯 C 端通用 AI 绘画不是大厂的终局，正在被"再吸收"进更大的入口（内容平台 / 办公套件 / 商家后台）
三条同向导流的事实：
1. 百度把独立入口 yige.baidu.com **下线并入** wenxin.baidu.com（2026-09-06 核验）[S#10]
2. 阿里把鹿班 **整体停服**（2025-06-30），能力拆回淘宝商家后台 [S#9]
3. AI 绘画变成高价位的拉新钩子：WPS AI 生图只在 **¥599/人/年** 的旗舰版开放，而 ¥199 档完全没有 [S#13][S#14]；美团的 AI 生图对 44.8 万门店「**零成本**」提供 [S#11]
→ **PM 行动**：独立 AI 绘画 App 的天花板是被验证过的窄门，revenue 高度依赖被嫁接到一个更大的 LTV 池。**面试话术建议**：不要讲"我们要做一个 AI 绘画工具"，讲"我们要解决哪个环节的视觉资产供给，这个环节现在由谁（平台/商家/办公）为它付费"。
置信度：**medium-high（下线/停服两条为单一 C 源，需复核；WPS 与美团两条为 A 级）**

### 判断 5｜图像生成的硬门槛已从"画得像"移到"中文长文本/图表渲染 + 可编辑结构化输出"
Model card/宣传口径转向：阿里 wan2.5-t2i-preview 主打「擅长中英文和小语种文字生成，支持复杂结构化长文本和图表、架构图等内容生成」[S#4]；wan2.6 主打「多图创意融合、商用级一致性、美学要素迁移与镜头光影精确控制」[S#13]；Seedream 5.0 主打「图层拆分（1 底图 + 16 图层）+ 交互编辑 + 原生多语种」[S#2]；可灵图片 3.0 主打「组图生成 + 2K/4K 直出 + 内置文本渲染」[S#21]。
IDC 2026 年 1–2 月实测把「语义理解、细节还原、风格多样性 + 生成效率与画质稳定性 + 内容安全性」列为评判维度 [S#1]。
→ **PM 行动**：如果做中文 2C/2B 场景，**"生成的图能不能直接改字、换个图层、保持系列款式一致"比"画质边际提升"更值钱**。这也是美图做 Agent Teams 多 Agent 电商设计工作流 [S#16]、稿定做分层 PSD 导出 [S#8] 的原因。
置信度：**high（A 级官方文档多源一致）**
